# Unified engine compatibility baseline

Baseline inspected: `37f4e8d0` (`HEAD` in this worktree). This records source behavior at the compatibility seam between `AgentRuntime`/`anima-harness` and `DurableAgentEngine`; it does not mark either consumer migrated. “Durable” below describes the engine loop and contracts. The only bundled store is an in-memory reference implementation, not a disk adapter.

## Optional environment boundary

Legacy `AgentRuntime` has no required workspace path in its public constructor or dialogue method. A run with an empty tool list succeeds without a filesystem setup. Filesystem-related authority belongs to explicit capability/host permission configuration; it must not be inferred from a working directory or host storage location. Policy grants bind owner, actor, agent definition, `workspace_id`, resource boundary, capability, manifest version, argument digest, risk, and validity window. The added regression test demonstrates that changing either owner or application-scope value prevents grant matching. This current wire field remains named `workspace_id`; it does not define the future opaque application-scope allocator or prove collision-safe mapping.

New regression coverage is in [`optional_environment_contract.rs`](../../../packages/core-rust/crates/anima-core/tests/optional_environment_contract.rs): `dialogue_requires_no_workspace` and `application_scope_cannot_alias_another_owners_grant`. The policy test exercises exact current public APIs and makes no production permission changes.

## Migration blockers and evidence limits

- The durable definition's `persona` field is not part of the model prompt today.
- Durable provider fallback and max-output-token settings are not wired through the engine request.
- Durable `Budget` supports more limits than the engine currently installs for a new run; actual finite shared resource accounting needs a parity gate.
- Durable engine has no steering API and no memory port. Memory is required for assistant and resident NPC profiles, so an execution-only run is not a migrated product profile.
- `InMemoryExecutionStore` snapshot import/export is useful reference behavior, not a production restart adapter. Passing its contract suite does not prove process-death recovery.
- The existing deterministic tests do not establish provider quality, storage durability, or multiplayer readiness. World membership is game-specific; assistant identity/memory cannot be coupled to a world.
