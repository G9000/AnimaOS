# Connected sources and preview edits implementation plan

> **For agentic workers:** Use superpowers:subagent-driven-development with bounded ownership and independent spec/quality review. The owner explicitly selected subagents; continue through implementation and verification without a redundant execution-choice gate.

**Goal:** Add explicitly shared connected project sources and reviewed targeted edits from existing previews.

**Architecture:** Reuse native provider readers and project knowledge custody for selected account content. Reuse document editing's reviewed proposal/apply pipeline for exact preview selections. SDK/web remain clients; private agent credentials, permissions, memory and approval authority remain separate.

**Tech Stack:** Existing Rust core/daemon, SQLite passage store, TypeScript SDK, React console and native document worker. No new service or OAuth stack.

Specs: [connected sources](../specs/2026-10-29-connected-project-sources-design.md), [preview editing](../specs/2026-10-29-click-edit-previews-design.md).
