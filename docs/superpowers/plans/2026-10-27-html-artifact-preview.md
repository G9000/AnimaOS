# HTML artifact preview implementation plan

**Goal:** Remove automatic saved-report cards from chat and open actual HTML file references in a closable right-side viewer.

**Architecture:** SessionView mounts a conversation-scoped file viewer instead of ChatResultsLayout. Markdown HTML links and literal inline HTML paths open exact file bytes through the existing authenticated, bounded workspace download endpoint. HTML executes inside an opaque sandbox nested in a trusted wrapper whose CSP prevents remote navigation. A source- and nonce-checked bridge isolates local saving to one file. Closing removes the viewer entirely; the original message link remains. A separate-window option prepares a fresh snapshot at activation.
