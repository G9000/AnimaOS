# Agent Skill Lifecycle Implementation Plan

**Goal:** Agents create, update, remove and undo skills in Free mode. Strict mode requires owner approval. Reuse the current Rust skill service, package validation, registry, trash and control-plane persistence.

**Approved design:** Keep propose_skill for creation and updates, including Strict review drafts. Add remove_skill, undo_skill and read-only skill_history. Removal and undo use runtime write approvals. Helpers cannot mutate shared skills.
