# Remove Nx and keep Bun workspaces

**Goal:** Make `bun dev` and the repository's build, test, typecheck, release, and CI workflows run without Nx, its daemon, plugins, or socket configuration.

**Design:** Keep the existing Bun workspace layout and add runnable Rust host manifests to the workspace. Use package scripts and Bun's dependency-aware workspace execution for JavaScript projects; Cargo continues to own Rust dependency ordering. Keep the existing dev process supervisor, replacing its Nx child commands with Bun scripts. A small command wrapper retains owned temporary-directory cleanup for test commands without modifying the parent process environment.

## Command interface

- Root: `bun dev`, `bun run build`, `bun run test`, `bun run typecheck`, `bun run lint`.
- Focused workspace: `bun run --filter <name> <script>`.
- Rust: root `daemon`, `rust:build`, `rust:test`, `rust:lint`; focused `core-rust`, `rust-daemon`, and `anima` workspace scripts preserve existing acceptance, packaging, and evaluation command names.
- Browser acceptance: `bun run --filter @animaos/web-e2e e2e`, `e2e-ci`, `e2e-console`, and `deployment-contracts`.
- Test scripts use `tools/workspace-dev/scripts/run-vitest.ts` or the generic `run-task.ts` wrapper so OS scratch stays outside the checkout and is removed after success or failure.

## Ownership

- Primary agent: root package and lockfile; tools/workspace-dev; Rust host/core manifests; deployment tooling/contracts; integration and final verification.
- Package migration agent: apps/packages manifests and TypeScript/Playwright configuration, excluding packages/core-rust.
- CI/documentation agent: .github workflows and generated release inputs; active docs/READMEs; repository-local agent/editor/MCP integration and Nx skill cleanup.

## Constraints

Preserve runtime/core boundaries, existing output/report directories, package dependency order, Rust/native CI coverage, explicit non-Nx configuration, and unrelated edits. Do not remove generic support for recognizing Nx commands in other repositories or rewrite historical records. Keep Cargo/Bun caches; only remove Nx-specific configuration and task-owned scratch.

## Validation evidence

- Frozen Bun install passes with Nx and all `@nx/*` packages removed.
- Root workspace build and TypeScript check pass. Both Astro sites, browser apps, SDK/TUI/CLI, Rust core, and native hosts build through Bun scripts.
- JavaScript package tests pass, including 36 launcher/temporary-lifecycle tests and 2,275 web tests (one skipped).
- Native packaging contracts: 11 passed. Harness driver regressions: 7 passed. Deployment contracts: 4 passed.
- Playwright discovery passes for the main (48), console (76), and focused companion (3) tests. Console discovery is isolated from the main suite, and CI runs both suites after installing browser dependencies.
- Plain `bun dev` passes with `NX_SOCKET_DIR` absent and an ephemeral profile: daemon, web, playground, public docs, and contributor docs all return HTTP 200. The owned process tree stops and all five ports close afterward.
- Full root `bun run test` passes, including Rust core, daemon, supervisor, and JavaScript workspaces. The daemon unit suite reports 3,247 passed and 37 ignored, followed by passing integration tests.
- Root lint reaches all workspace checkers but fails on existing lint errors in unchanged SDK, web, TUI, and landing source. No unrelated source fixes are included.
- Combined implementation review is complete. Task-owned migration and smoke-test scripts were removed, and the smoke test removed its isolated OS scratch. Cargo and tool caches are retained.
