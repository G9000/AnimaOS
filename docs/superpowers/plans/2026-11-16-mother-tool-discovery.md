# Mother tool discovery repair

The live conversation found the native memory search but missed Mother's permitted
record reader. Its MCP execution alias is opaque, and catalog ranking only indexed
that alias and the description. Generic native `read` names beat relevant external
descriptions. Calling the exact admitted alias succeeded, so the repair concerns
discovery rather than pairing, credentials or storage.

Keep the alias, descriptor, captured authority and dispatch receipt unchanged.
Index the current agent-owned MCP remote name and connection label as discovery
identity. Include those two non-secret fields in bounded discovery summaries.
Treat punctuation in labels consistently so `Mother` can match `M.O.T.H.E.R`.
An exact native execution name must retain priority over a matching remote name.
Current revocation, connection generation, schema and grant checks still decide
whether a result may be returned or hydrated.

1. Add synthetic regressions for the two failed live queries, connection-label
   lookup, exact native-name priority and revocation. Confirm the ranking cases
   fail before changing production behavior.
2. Implement discovery identity without changing permission decisions or stored
   configuration. Run the catalog checks, full managed Rust suite, formatting and
   lint, and build the native package with static web assets. Retain the 32 GiB
   cache cap and use owner-private synthetic temporary roots.
3. Back up the active profile, install the qualified package outside build caches
   and restart gracefully against the existing data. Retain login startup,
   credentials, additive bindings and native memory. In a fresh real conversation,
   ask the configured model to discover Mother readers by ordinary descriptions
   and retrieve both Mother and native evidence. Supply no exact MCP tool name.
   Verify the discovery results and actual tool calls, unchanged original memory
   entries/history and an empty sharing queue. Record any new ordinary private
   task captures or learning separately. Preserve the diagnostic chat and private
   evidence; no proposal or sharing action is authorized by this test.
