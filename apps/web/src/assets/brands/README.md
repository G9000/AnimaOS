# Brand marks

Marks for the services Anima connects to, shown by `BrandIcon`.

- Source: [Simple Icons](https://github.com/simple-icons/simple-icons), CC0 1.0.
  Gmail, Google Calendar, Google Drive, Telegram, Discord, WhatsApp and Slack
  come from v13.21.0. Outlook and OneDrive come from v11.14.0, the last
  release that carried them.
- Each file is the original single path with a brand colour added as `fill`
  so it reads on a dark surface. Slack's own mark is four-colour; the file
  uses its red.
- The marks are trademarks of their owners. Anima uses them only to say which
  service a connection is, and does not imply endorsement.
