Values come from the process environment at startup and are read once. Parsing for the numeric limits is in `hosts/rust-daemon/src/app/entry.rs`: `0`, negative or non-numeric values fail startup with `<NAME> must be a positive integer`. The long-form table is in `hosts/rust-daemon/README.md`.

<Aside type="note" title="Installed copies">
  The packaged `anima` program sets many of these for the daemon it supervises (workspace, ports, data files, allowed origins, keychain namespace). Variables already present in the process environment win over the packaged defaults. See [Packaged Anima](/packaged-anima/#what-the-supervisor-gives-the-daemon).
</Aside>

## Model Providers

The table mirrors `anima-model-adapters/src/catalog.rs`. A key from the environment is key `env` in that provider's key pool; more keys can be added at runtime (see [Persistence](/hosts/rust-daemon/persistence/#provider-key-pool)). The `chatgpt` provider needs no variable: it signs in with a device code and stores tokens in the OS credential store.

## Server

| Variable | Default | Description |
|----------|---------|-------------|
| `ANIMAOS_RS_HOST` | `127.0.0.1` | Bind host. A non-loopback host makes owner-only routes answer `403` |
| `ANIMAOS_RS_PORT` | `8080` | Bind port (the packaged program uses `8787`) |
| `ANIMAOS_RS_MAX_REQUEST_BYTES` | `65536` | Body limit for ordinary JSON routes |
| `ANIMAOS_RS_REQUEST_TIMEOUT_SECS` | `30` | Timeout for standard routes (`408`) |
| `ANIMAOS_RS_RUN_REQUEST_TIMEOUT_SECS` | `600` | Response timeout for blocking run routes; an admitted run continues |
| `ANIMAOS_RS_MAX_CONCURRENT_RUNS` | `8` | Runs executing at once across the daemon. Legacy run routes return `503` when none is free |
| `ANIMAOS_RS_MAX_RUNS_PER_AGENT` | `3` | Concurrent runs of one agent across rooms; must be 1 to 64. Same-room runs queue in order |
| `ANIMAOS_RS_MAX_BACKGROUND_PROCESSES` | `8` | Concurrent `bg_start` processes |
| `ANIMAOS_RS_SESSION_EVENT_BUFFER` | `1024` | Per-agent live event buffer; 1 to 65536; a slow stream gets `stream.resync` |
| `ANIMAOS_RS_EVENT_BUFFER` | `64` | Broadcast buffer behind swarm event streams (`DEFAULT_EVENT_BUFFER` in `events.rs`); a lagging subscriber gets `swarm:lagged` |
| `ANIMAOS_RS_DB_MAX_CONNECTIONS` | `10` | Postgres pool size |
| `ANIMAOS_RS_API_KEY` | none | Shared API key required on non-exempt routes (`Authorization: Bearer` or `x-api-key`) |
| `ANIMAOS_WORKSPACE_ROOT` | current directory | Workspace root for native file tools when no workspace is configured |
| `ANIMAOS_RS_KEYCHAIN_NAMESPACE` | none | `[a-z0-9-]{1,32}`; prefixes OS credential-store service names so an installed copy and a dev copy do not share items (installed uses `installed`) |
| `RUST_LOG` | `anima_daemon=info,tower_http=info` | `tracing` filter. `debug` and `trace` let far more request and provider detail into the console and the log tail |

## Owner Authorization and Supervision

| Variable | Description |
|----------|-------------|
| `ANIMA_ALLOWED_UI_ORIGINS` | Comma-separated extra exact browser origins allowed to act as the local owner. Built-in dev origins are `http://localhost:4200`, `http://127.0.0.1:4200`, `http://localhost:4201` and `http://127.0.0.1:4201`, except under a supervisor, where only the configured ones count. No wildcards |
| `ANIMA_LOCAL_ADMIN_TOKEN`, `ANIMA_LOCAL_ADMIN_TOKEN_FILE` | Bearer token for originless owner clients; also signs console sessions. The `_FILE` form (a path) wins and an unreadable file means no token. Without a token, originless owner mutations are disabled. Compared in constant time, never returned or logged |
| `ANIMA_SUPERVISOR_URL`, `ANIMA_SUPERVISOR_TOKEN`, `ANIMA_SUPERVISOR_TOKEN_FILE` | Set by `anima`: the supervisor control API and its bearer token (the `_FILE` form wins). Both URL and token must be set to enable the `/api/system` relay |
| `ANIMA_PUBLIC_BASE_URL` | Public origin for OAuth callbacks (Google, Gmail, Outlook). Canonical origin only (no credentials, path, query or fragment); loopback HTTP is allowed. Default `http://127.0.0.1:8080`. An invalid value fails startup |
| `ANIMA_GOOGLE_CLIENT_ID`, `ANIMA_GOOGLE_CLIENT_SECRET` | Google OAuth app for Calendar, Gmail and Drive, as an alternative to saving it in the credential store from the console |
| `ANIMA_MICROSOFT_CLIENT_ID`, `ANIMA_MICROSOFT_CLIENT_SECRET`, `ANIMA_MICROSOFT_TENANT` | Microsoft OAuth app for Outlook |

## Persistence

| Variable | Default | Description |
|----------|---------|-------------|
| `ANIMAOS_RS_PERSISTENCE_MODE` | `memory` | `memory` or `postgres`. `postgres` requires `DATABASE_URL` and fails startup if it is unavailable or migrations fail |
| `DATABASE_URL` | none | Postgres connection string |
| `ANIMAOS_RS_CONTROL_PLANE_FILE` | none | JSON control-plane snapshot (agents, sessions, runs, approvals, connectors, settings). Without it, and without Postgres, state is ephemeral |
| `ANIMAOS_RS_HISTORY_SQLITE_FILE` | `history.sqlite` beside the control-plane file | SQLite history store. A Postgres control plane uses Postgres `history_*` tables unless this is set. With neither, history is in memory (100,000 rows per table) |
| `ANIMAOS_RS_MEMORY_FILE` | none | JSON memory snapshot. Set at most one of this and the SQLite variable |
| `ANIMAOS_RS_MEMORY_SQLITE_FILE` | `memory.sqlite` beside the control-plane file | SQLite memory snapshot and, by default, embedding vectors |
| `ANIMAOS_RS_PROVIDER_KEYS_FILE` | `provider-keys.json` beside the control-plane file | Provider key pool file; without either, added keys last until restart |

Memory store choice order: explicit JSON or SQLite file, then Postgres `host_snapshots`, then `memory.sqlite` beside the control-plane file, then memory-only. Details: [Persistence](/hosts/rust-daemon/persistence/).

## Memory

| Variable | Default | Description |
|----------|---------|-------------|
| `ANIMAOS_RS_MEMORY_EMBEDDINGS` | `fastembed` | `fastembed`, `local`, `ollama`, `openai`, `openai-compatible` or `disabled`. If unset while `ANIMAOS_RS_MEMORY_EMBEDDING_DIMENSIONS` is set, the daemon keeps `local` and logs a warning |
| `ANIMAOS_RS_MEMORY_EMBEDDING_MODEL` | per mode | `fastembed`: `intfloat/multilingual-e5-small` (aliases such as `multilingual-e5-base`, `multilingual-e5-large`, `bge-m3`, `paraphrase-multilingual-minilm-l12-v2`); `openai` and `openai-compatible`: `text-embedding-3-small`; `ollama`: `nomic-embed-text` |
| `ANIMAOS_RS_MEMORY_EMBEDDING_DIMENSIONS` | per mode | `local` 96 (minimum 24); `openai` 1536; `ollama` 768; `fastembed` uses the model's fixed size and rejects mismatches |
| `ANIMAOS_RS_MEMORY_EMBEDDINGS_BASE_URL` | per mode | OpenAI-compatible base URL (`https://api.openai.com/v1`, or `http://127.0.0.1:11434/v1` for Ollama). `OPENAI_BASE_URL` and `OLLAMA_BASE_URL` are also read |
| `ANIMAOS_RS_MEMORY_EMBEDDINGS_API_KEY` | none | Key for provider modes. `openai` needs this or `OPENAI_API_KEY`; `ollama` and `openai-compatible` treat it as optional |
| `ANIMAOS_RS_MEMORY_EMBEDDINGS_TIMEOUT_MS` | `15000` | HTTP timeout for provider embedding calls |
| `ANIMAOS_RS_MEMORY_EMBEDDINGS_CACHE_DIR` | `models/` beside the memory store, else `~/Library/Caches/animaos/models` (macOS) or `$XDG_CACHE_HOME/animaos/models` / `~/.cache/animaos/models` | fastembed model cache |
| `ANIMAOS_RS_MEMORY_EMBEDDINGS_SHOW_DOWNLOAD_PROGRESS` | `false` | Show model download progress bars |
| `ANIMAOS_RS_MEMORY_EMBEDDINGS_SQLITE_FILE` | the memory SQLite file | SQLite file for vectors (separate `memory_embeddings` tables) |
| `ANIMAOS_RS_MEMORY_TEXT_ANALYZER` | `multilingual` | BM25 analyzer; `multilingual`, `unicode` and `default` select the one profile that exists |
| `ANIMAOS_RS_MEMORY_QUERY_EXPANDER` | none | `locomo` / `locomo-benchmark` turns on benchmark query expansion; `none`, `off`, `disabled` or unset leave it off |
| `ANIMAOS_RS_MEMORY_PROVIDER` | `none` | External memory provider id. Only `none` is built in; an unknown id stops boot |

## Optional Features

| Variable | Description |
|----------|-------------|
| `ANIMAOS_STT_ENABLED` | `true` or `1` enables owner-requested speech-to-text with the server's OpenAI Platform API key (ChatGPT subscription credentials are excluded). Off by default |
| `ANIMAOS_TTS_ENABLED` | `true` or `1` enables owner-requested speech output with the same key. Independent of STT. Off by default |
| `ANIMAOS_RS_BROWSER_CONFIG_FILE` | Path to the immutable browser-tool startup configuration (loaded at boot; invalid configuration fails startup) |
| `ANIMAOS_RS_TOOL_RPC_PYTHON_PATH` | Absolute path to an existing Python 3.10+ interpreter. Enables `execute_code` for agents granted it; no PATH discovery. Invalid path fails startup |
| `ANIMAOS_RS_CHECKPOINT_ROOT` | Absolute private directory outside the workspace for native-file checkpoints. **Windows only**: on other platforms setting it fails startup |
| `ANIMAOS_BUILD_REVISION` | Build-time variable (read with `option_env!`), reported as `buildRevision` by `/api/status` |

## Development

| Variable | Description |
|----------|-------------|
| `ANIMAOS_DEV_EPHEMERAL` | `1` makes `bun dev` start the daemon without a persistent control-plane file (read by `tools/workspace-dev`, not by the daemon) |
| `ANIMAOS_DEV_SIGNING_IDENTITY` | macOS: code-signing identity used by `rust-daemon:dev` so keychain "Always Allow" survives rebuilds (see [Local Development](/hosts/rust-daemon/local/)) |

## Example Profiles

Minimal, in-memory:

```bash
ANTHROPIC_API_KEY=sk-ant-... cargo run -p anima-daemon
```

Durable local state (control plane, history and memory all live in `./data`):

```bash
ANIMAOS_RS_CONTROL_PLANE_FILE=./data/control-plane.json \
ANTHROPIC_API_KEY=sk-ant-... \
cargo run -p anima-daemon
```

Postgres with in-process semantic embeddings:

```bash
ANIMAOS_RS_PERSISTENCE_MODE=postgres \
DATABASE_URL=postgres://user:pass@localhost/anima \
ANIMAOS_RS_MEMORY_EMBEDDINGS=fastembed \
ANTHROPIC_API_KEY=sk-ant-... \
cargo run -p anima-daemon
```

Ollama embeddings:

```bash
ANIMAOS_RS_CONTROL_PLANE_FILE=./data/control-plane.json \
ANIMAOS_RS_MEMORY_EMBEDDINGS=ollama \
ANIMAOS_RS_MEMORY_EMBEDDING_MODEL=nomic-embed-text \
cargo run -p anima-daemon
```

For container staging see [Staging Deployment](/hosts/rust-daemon/staging/).
