This page is the shortest reliable path to getting the whole repo running locally.

## What "Whole Repo" Means Here

The normal loop (`bun dev`, through `tools/workspace-dev`) starts:

- the Rust daemon (`anima-daemon`), the only host
- the web console
- the playground
- the public docs app
- the contributor docs app

`bun dev` defaults to the `rust` host, so `bun dev` and `bun dev --host rust` are equivalent. `rust` is the only accepted host key.

## 5-Minute Bring-Up

<Steps>

1. Clone the repo and enter it.

   ```bash
   git clone https://github.com/G9000/animaos.git
   cd animaos
   ```

2. Install JavaScript dependencies.

   ```bash
   bun install
   ```

3. Verify the Rust toolchain.

   ```bash
   cargo --version
   rustc --version
   ```

4. Optionally set a provider key in your shell. You can also add keys later in the console (**Settings**), or sign in with a ChatGPT subscription.

   ```bash
   export ANTHROPIC_API_KEY=sk-ant-...
   # or
   export OPENAI_API_KEY=sk-...
   ```

5. Start the full workspace.

   ```bash
   bun dev
   ```

</Steps>

<Aside type="tip">
  The launcher checks `http://127.0.0.1:8080/api/health` first. If a daemon is
  already running there, `bun dev` reuses it and only starts the browser
  surfaces and docs apps.
</Aside>

<Aside type="note">
  `bun dev` persists the daemon's data in `~/.animaos-swarm/data/` (agents,
  history, memory). Set `ANIMAOS_DEV_EPHEMERAL=1` for a throwaway run, or
  `ANIMAOS_RS_CONTROL_PLANE_FILE=./data/control-plane.json` for a project-local
  store. That default folder is the one an installed `anima` also uses.
</Aside>

## What You Should See

| Surface          | URL                     | Notes                           |
| ---------------- | ----------------------- | ------------------------------- |
| Rust daemon      | `http://127.0.0.1:8080` | HTTP API, SSE, `/docs` (Scalar) |
| Web console      | `http://127.0.0.1:4200` | Main browser UI                 |
| Playground       | `http://127.0.0.1:4201` | Interactive runtime playground  |
| Public docs      | `http://127.0.0.1:4321` | User-facing docs                |
| Contributor docs | `http://127.0.0.1:4322` | This site                       |

Quick checks:

```bash
curl http://127.0.0.1:8080/health
curl http://127.0.0.1:8080/ready
```

Open the console from `4200`, not the daemon's port: the console proxies the daemon and its origin is the one the daemon accepts for owner actions.

## Choose the Right Loop

Use the smallest loop that matches your change.

### Full repo loop

For host plus browser surfaces, docs or overall integration.

```bash
bun dev
```

### Host-only loop

For changes confined to the Rust daemon.

```bash
bun run --filter rust-daemon dev
```

### Web-only and playground-only loops

```bash
bun run --filter @animaos/web dev
bun run --filter @animaos/playground dev
```

Both proxy to the daemon at `UI_BACKEND_ORIGIN` (default from the launcher: `http://127.0.0.1:8080`), so start a daemon too.

### Docs-only loop

```bash
bun run --filter @animaos/docs dev
bun run --filter @animaos/contributor-docs dev
```

### CLI plus daemon loop

For agency creation, launch, chat or TUI flows. Terminal 1:

```bash
bun run daemon
```

Terminal 2:

```bash
bun run build:cli-sdk
bun run animaos create agent my-agent --provider openai --model gpt-4o-mini
cd my-agent
bun run animaos launch "your task"
```

`create` writes a local workspace and does not need the daemon. `launch`, `run`, `chat`, `agents` and `assistant` are daemon-backed.

## Recommended Local Host Profiles

### Default host development

Durable agents, history and memory in `./data` with cheap deterministic vectors:

```bash
ANIMAOS_RS_CONTROL_PLANE_FILE=./data/control-plane.json \
ANIMAOS_RS_MEMORY_EMBEDDINGS=local \
ANTHROPIC_API_KEY=sk-ant-... \
cargo run -p anima-daemon
```

### Postgres host development

For durable step-log retry behavior or Postgres-backed snapshots and history:

```bash
ANIMAOS_RS_PERSISTENCE_MODE=postgres \
DATABASE_URL=postgres://user:pass@localhost/anima \
ANTHROPIC_API_KEY=sk-ant-... \
cargo run -p anima-daemon
```

## Daily Commands

```bash
bun run build                     # build every workspace
bun run test                      # test every workspace
bun run typecheck                 # check workspace types
bun run lint                      # oxlint over packages and apps

bun run --filter rust-daemon test
bun run --filter @animaos/contributor-docs build
bun run --filter @animaos/docs build
```

## Before You Push

| You changed                          | Run                                                                                                     |
| ------------------------------------ | ------------------------------------------------------------------------------------------------------- |
| Rust host or core crates             | `bun run --filter rust-daemon test` (runs `core-rust:test` first)                                       |
| Dev launcher (`tools/workspace-dev`) | `bun run --filter workspace-dev test`                                                                   |
| A TypeScript package                 | the package's `test`, `typecheck` and `build` targets, for example `bun run --filter @animaos/sdk test` |
| Contributor docs                     | `bun run --filter @animaos/contributor-docs build`                                                      |
| Public docs                          | `bun run --filter @animaos/docs build`                                                                  |
| Several areas                        | `bun run build`, `bun run test`, and `bun run typecheck`                                                |

Do not call work complete until the relevant commands pass in the current tree.

## Windows Notes

- A running daemon can keep `target/cargo/debug/anima-daemon.exe` locked.
- If Rust validation hits that lock, rerun with an isolated target directory:

```bash
CI=1 CARGO_TARGET_DIR=target/cargo/validation-rust-daemon bun run --filter rust-daemon test
```
