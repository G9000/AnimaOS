## Subscribe to the Stream

```typescript
const stream = client.swarms.subscribe(swarmId);

for await (const { event, data } of stream) {
  console.log(event, data);
}
```

`subscribe(swarmId, init?)` returns an async generator of `DaemonEvent<SwarmStreamEventPayload>`: `event` is the SSE event name and `data` the parsed payload. It ends when the connection closes, and an unknown swarm id fails with a `404` `DaemonHttpError`. Reconnecting is up to you.

## Event Names

The daemon publishes these event names on a swarm's stream:

| Event | Payload | Meaning |
|-------|---------|---------|
| `swarm:created`, `swarm:running`, `swarm:completed` | `SwarmEventPayload` | Swarm-level state update; `swarm:completed` also carries the final `result` |
| `swarm:message` | `SwarmMessagePayload` | An agent-to-agent message |
| `agent:terminated` | `SwarmAgentEventPayload` | An agent was terminated |
| `task:started`, `task:completed` | `SwarmAgentEventPayload` | An agent's task began or finished |
| `task:failed` | `SwarmTaskFailedPayload` | An agent's task failed |
| `tool:before` | `SwarmToolBeforePayload` | Tool invocation starting |
| `tool:after` | `SwarmToolAfterPayload` | Tool invocation finished |
| `agent:tokens` | `SwarmAgentTokensPayload` | Token usage update |
| `swarm:lagged` | `{ missed: number }` | The consumer fell behind the daemon's broadcast buffer and missed events; refetch state with `swarms.get()` |

## Payload Shapes

| Payload | Key fields |
|---------|-----------|
| `SwarmEventPayload` | `swarmId`, `state` (`SwarmState`), `result` (`DaemonTaskResult` or `null`) |
| `SwarmMessagePayload` | `swarmId`, `message` |
| `SwarmAgentEventPayload` | `agentId`, `agentName`, optional `eventId`, `timestampMs` |
| `SwarmTaskFailedPayload` | the above plus `error` |
| `SwarmToolBeforePayload` | the above plus `toolName`, `args` |
| `SwarmToolAfterPayload` | the above plus `toolName`, `status`, `durationMs`, optional `result` |
| `SwarmAgentTokensPayload` | the above plus `usage` (`TokenUsage`) |

## Monitor Tool Activity

```typescript
for await (const { event, data } of client.swarms.subscribe(swarmId)) {
  if (event === 'tool:after' && 'toolName' in data && 'status' in data) {
    console.log(`[${data.agentName}] ${data.toolName}: ${data.status} (${data.durationMs}ms)`);
  }

  if (event === 'task:failed' && 'error' in data) {
    console.error(`[${data.agentName}] FAILED: ${data.error}`);
  }

  if (event === 'swarm:lagged') {
    console.warn('Missed events; refetch the swarm state');
  }
}
```

## Cancel a Stream

```typescript
const controller = new AbortController();

const streamTask = (async () => {
  for await (const event of client.swarms.subscribe(swarmId, {
    signal: controller.signal,
  })) {
    console.log(event.event, event.data);
  }
})();

setTimeout(() => controller.abort(), 30_000);

await streamTask.catch((error) => {
  if (!(error instanceof Error && error.name === 'AbortError')) throw error;
});
```

<Aside type="tip">
  Use snapshots (`swarms.get()`) for point-in-time state and SSE for live surfaces. They complement each other. Subscribe before calling `swarms.run()` so the early events are not missed.
</Aside>
