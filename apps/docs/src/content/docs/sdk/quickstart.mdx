## Prerequisites

The SDK is a client for the Rust daemon (`hosts/rust-daemon`). It does not embed a runtime, so the daemon must be running and have a model provider available.

<Steps>

1. **Start the daemon**

   From the repository root:

   <Tabs>
     <TabItem label="bun">
       ```bash
       bun run daemon
       ```
     </TabItem>
     <TabItem label="cargo">
       ```bash
       cargo run --manifest-path Cargo.toml -p anima-daemon
       ```
     </TabItem>
   </Tabs>

   It listens on `http://127.0.0.1:8080` unless `ANIMAOS_RS_HOST` or `ANIMAOS_RS_PORT` say otherwise. An installed `anima` program serves the same API on port `8787` by default.

2. **Give it a model**

   Either set a provider key in the daemon's environment, or save keys and the ChatGPT subscription in the web console (Settings, Model).

   ```bash
   export OPENAI_API_KEY="sk-..."
   # and/or
   export ANTHROPIC_API_KEY="sk-ant-..."
   ```

   You can also pass `settings.apiKey` and `settings.baseUrl` on an agent config; the CLI does this per request. See [Providers & Environment](/cli/providers/) for the full list of provider names and variables.

3. **Check that it is up**

   ```bash
   curl http://127.0.0.1:8080/health
   # {"status":"ok"}
   ```

</Steps>

<Aside type="tip">
  `bun dev --host rust` starts the daemon, the web console on `http://localhost:4200` and the playground. `bun run daemon` is the smallest loop when you only need the API.
</Aside>

## Installation

`@animaOS-SWARM/sdk` is a private workspace package in this repository; it is not published to npm. Build it, and depend on it from another workspace package:

```bash
bun install --frozen-lockfile
bun x nx run @animaOS-SWARM/sdk:build
```

```json
{
  "dependencies": {
    "@animaOS-SWARM/sdk": "workspace:*"
  }
}
```

The package is ESM and needs a runtime with global `fetch` (or pass your own through `createDaemonClient({ fetch })`).

## Mental Model

- `createDaemonClient()` returns one `DaemonClient`.
- `client.agents` registers agents and runs a task to completion in one blocking call.
- `client.sessions`, `client.runs` and `client.events` are the console's model: sessions hold conversations, accepted runs execute in the background, and an SSE stream reports progress.
- `client.swarms` coordinates a manager and workers; `client.memories` reads and writes long-term memory.
- Execution, tools and persistence stay in the daemon. The SDK only talks to it.

## Single-Agent Flow

```typescript
import { agent, createDaemonClient } from '@animaOS-SWARM/sdk';

const client = createDaemonClient();

await client.health();

const researcher = await client.agents.create(
  agent({
    name: 'researcher',
    provider: 'openai',
    model: 'gpt-4o-mini',
    system: 'You are a research assistant. Provide concise, factual answers.',
  })
);

console.log('Created agent:', researcher.state.id);

const run = await client.agents.run(researcher.state.id, {
  text: 'What are the main types of neural networks?',
  metadata: { retryKey: 'neural-networks-quickstart' },
});

if (run.result.status === 'success') {
  console.log(run.result.data?.text);
} else {
  console.error('Run failed:', run.result.error);
}
```

`agent()` is an identity function that types the `AgentConfig` shape; a plain object works too. `agents.run()` blocks until the run ends and returns `{ agent, result }`. The daemon answers `408` if a run outlives `ANIMAOS_RS_RUN_REQUEST_TIMEOUT_SECS` (600 by default) while it keeps running; for long work use [Sessions & Runs](/sdk/sessions/).

## Memory Flow

```typescript
const memory = await client.memories.create({
  agentId: researcher.state.id,
  agentName: researcher.state.name,
  type: 'fact',
  content: 'User prefers concise technical answers.',
  importance: 0.8,
  tags: ['preference', 'style'],
  scope: 'shared',
});

// search() results are flat: the memory fields plus `score`
const matches = await client.memories.search('concise technical', {
  agentId: researcher.state.id,
  limit: 5,
});

// recall() results nest the memory: { memory, score, lexicalScore, ... }
const recalled = await client.memories.recall('How should I respond?', {
  agentId: researcher.state.id,
  entityId: 'user-1',
  limit: 3,
});

console.log(memory.id, matches[0]?.content, recalled[0]?.memory.content);
```

Memory `type` is one of `fact`, `observation`, `task_result` or `reflection`.

## Swarm Flow

```typescript
import { agent, swarm } from '@animaOS-SWARM/sdk';

const editorialSwarm = await client.swarms.create(
  swarm({
    strategy: 'supervisor',
    manager: agent({
      name: 'editor',
      provider: 'openai',
      model: 'gpt-4o',
      system: 'Break work into steps, review outputs, and synthesize the final answer.',
    }),
    workers: [
      agent({
        name: 'researcher',
        provider: 'openai',
        model: 'gpt-4o-mini',
        system: 'Research the assigned topic and return concise findings.',
      }),
      agent({
        name: 'writer',
        provider: 'openai',
        model: 'gpt-4o',
        system: 'Turn approved findings into polished output.',
      }),
    ],
  })
);

const result = await client.swarms.run(editorialSwarm.id, {
  text: 'Write a short launch announcement for our Rust daemon.',
});

console.log(result.result.status, result.swarm.status);
```

`swarms.create()` returns the `SwarmState` itself, so the swarm id is `editorialSwarm.id`. For live telemetry, iterate `client.swarms.subscribe(editorialSwarm.id)`; payloads are covered in [Event Streaming](/sdk/swarms/events/).

## Error Handling

```typescript
import { DaemonHttpError, DaemonConnectionError } from '@animaOS-SWARM/sdk';

try {
  await client.agents.run('AGENT_ID', { text: 'Hello' });
} catch (error) {
  if (error instanceof DaemonHttpError) {
    console.error(`HTTP ${error.status}:`, error.body);
  } else if (error instanceof DaemonConnectionError) {
    console.error('Connection failed:', error.cause);
  } else {
    throw error;
  }
}
```

| Error | Property | Meaning |
|-------|----------|---------|
| `DaemonHttpError` | `status: number` | HTTP status code from the daemon |
| `DaemonHttpError` | `body: unknown` | Parsed response body (JSON when possible) |
| `DaemonConnectionError` | `cause: unknown` | Original fetch or network error |
