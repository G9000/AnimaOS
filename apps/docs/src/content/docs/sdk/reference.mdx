The SDK is one `DaemonClient` with typed sub-clients, plus shared types. It is a client for the [Rust daemon](https://github.com/G9000/animaos/tree/main/hosts/rust-daemon) over HTTP and SSE; the daemon's own route inventory and OpenAPI document (`GET /openapi.json`, browsable at `/docs`) are the contract behind it. Methods marked **owner** use owner routes and need `Authorization: Bearer <ANIMA_LOCAL_ADMIN_TOKEN>` from a script ([Authentication](/sdk/client/#authentication)).

All `signal` options are an `AbortSignal`. Unless noted, methods resolve to the unwrapped payload (for example `agents.get()` returns the `AgentSnapshot`, not `{ agent }`).

## `DaemonClient`

```typescript
import { createDaemonClient, DaemonClient } from '@animaos/sdk';

const client = createDaemonClient(options);
```

| `DaemonClientOptions` | Type | Default | Description |
|-----------------------|------|---------|-------------|
| `baseUrl` | `string` | `http://127.0.0.1:8080` | Daemon origin or path prefix; `''` for same-origin browsers |
| `fetch` | `FetchLike` | `globalThis.fetch` | Custom fetch (add auth headers here) |

| Method | Description |
|--------|-------------|
| `health()` | `GET /health`: `{ status: 'ok' }` |
| `capabilities()` | `GET /api/capabilities`: `DaemonCapabilities` |
| `requestJson<T>(path, init?)` | JSON request; objects in `body` are serialized, `FormData`, `Blob` and strings pass through |
| `requestText(path, init?)` | Text response (Markdown, CSV) |
| `requestBlob(path, init?)` | Binary response |
| `requestBoundedBlob(path, init, limits)` | Binary response with a strict size and content-type check |
| `requestNoBody(path, init, expectedStatus)` | Status-only call; the body is discarded |
| `subscribe<T>(path, init?)` | Async generator of `DaemonEvent<T>` (`event`, `data`, optional `id`) over SSE |

Sub-clients: `agents`, `swarms`, `memories`, `sessions`, `runs`, `events`, `attachments`, `approvals`, `automations`, `goals`, `mcp`, `skills`, `communityBundles`, `learning`, `usage`, `logs`, `status`, `system`, `workspace`, `agentFiles`, `agencies`, `connectors`, `voice`, `speech`, `browserScopes`, `chatgpt`.

### Errors

| Class | Thrown when | Properties |
|-------|-------------|------------|
| `DaemonHttpError` | Non-2xx response | `status`, `body` |
| `DaemonConnectionError` | The daemon cannot be reached or the body fails midway | `cause` |
| `DaemonTooOldError` | `sessions.list()` or `sessions.main()` on a daemon without sessions | `code: 'daemon_too_old'`, `agentId` |
| `StatusTooOldError` | `status.get()` on a daemon without `/api/status` | `code: 'daemon_too_old'` |

## Core Types

### `AgentConfig`

| Field | Type | Required |
|-------|------|----------|
| `name` | `string` | yes |
| `model` | `string` | yes |
| `provider`, `system`, `bio`, `lore`, `style` | `string` | no |
| `knowledge`, `topics`, `adjectives` | `string[]` | no |
| `tools` | `AgentToolInput[]` | no |
| `plugins` | `DaemonPluginDescriptor[]` | no |
| `settings` | `AgentSettings` | no |

`AgentSettings`: `temperature`, `maxTokens`, `timeoutMs`, `maxRetries` and an index signature for other keys.

### Snapshots and state

| Type | Fields |
|------|--------|
| `AgentSnapshot` | `state: DaemonAgentState`, `messageCount`, `messages: DaemonAgentMessage[]`, `eventCount`, `lastTask: DaemonTaskResult \| null` |
| `AgentSummary` | `AgentSnapshot` without `messages` |
| `DaemonAgentState` | `id`, `name`, `status`, `config: DaemonAgentConfig`, `createdAtMs`, `tokenUsage` |
| `AgentRunResponse` | `agent: AgentSnapshot`, `result: DaemonTaskResult` |
| `DaemonTaskResult<T>` | `status: 'success' \| 'error'`, `data: T \| null`, `error: string \| null`, `durationMs` |
| `DaemonContent` | `text`, `attachments: Attachment[] \| null`, `metadata: Record<string, unknown> \| null` |
| `SwarmState` | `id`, `status`, `agentIds`, `messages`, `results`, `tokenUsage`, `startedAt?`, `completedAt?` |

`AgentStatus` is `'idle' | 'running' | 'completed' | 'failed' | 'terminated'`. `SwarmStatus` is `'idle' | 'running' | 'completed' | 'failed'`. `SwarmStrategy` is `'supervisor' | 'dynamic' | 'round-robin'`. `UUID` is a branded string template.

### `Content`, `Attachment`, `TokenUsage`

| Type | Fields |
|------|--------|
| `Content` | `text`, optional `attachments: Attachment[]`, optional `metadata` |
| `Attachment` | `type: 'file' \| 'image' \| 'url'`, `name`, `data` |
| `TaskResult<T>` | `status`, optional `data`, `error`, `durationMs` (the in-process shape) |
| `TokenUsage` | `promptTokens`, `completionTokens`, `totalTokens` |

### Tool descriptors

`AgentToolInput` is `string | { name: string; description?: string; parameters?: Record<string, unknown>; examples?: DaemonToolDescriptor['examples'] }`. `DaemonToolDescriptor` is `{ name, description, parameters, examples }`; `DaemonPluginDescriptor` is `{ name, description }`.

### Memory types

`MemoryType` is `'fact' | 'observation' | 'task_result' | 'reflection'`, `MemoryScope` is `'shared' | 'private' | 'room'`, and `RelationshipEndpointKind` is `'agent' | 'user' | 'system' | 'external'`. `Memory`, `MemorySearchResult` (a `Memory` plus `score`), `MemorySearchOptions`, `AgentRelationship`, `NewAgentRelationshipInput` and `AgentRelationshipOptions` are exported from the same module.

### Provider key types

`ProviderKey`, `ProviderKeys`, `AddProviderKeyInput`, `KeyStrategy` (`fill_first`, `round_robin`, `random`, `least_used`; also exported as `KEY_STRATEGIES`) and `ModelChoice` (`{ provider, model }`) are exported as types. They describe the daemon's `/api/provider-keys` routes, which have no SDK client yet; use `client.requestJson` against them.

## Helper Functions

| Function | Signature | Purpose |
|----------|-----------|---------|
| `agent(config)` | `<T extends AgentConfig>(config: T) => T` | Typed `AgentConfig` |
| `swarm(config)` | `<T extends SwarmConfig>(config: T) => T` | Typed `SwarmConfig` |
| `createDaemonClient(options?)` | `DaemonClient` | Create the client |
| `isTerminalRunStatus(status)` | `boolean` | `completed`, `failed`, `cancelled` or `interrupted` |
| `speechTextIsValid(text)` | `boolean` | Whether text fits speech-output limits |

The daemon-health helpers `DAEMON_CONNECTION_LOST_MESSAGE`, `DAEMON_HEALTHY_MESSAGE`, `DAEMON_HEALTH_UNAVAILABLE_MESSAGE`, `DAEMON_RECOVERED_MESSAGE`, `describeDaemonWarningTransition` and `formatDaemonUnreachableWarning` produce the wording the CLI and TUI show when the daemon drops and returns.

<Aside type="note">
  Several areas the daemon serves have no SDK client: Telegram connectors, agent autonomy modes, provider API keys, the side-task model, coding apps and foreign (Claude Code and Codex) session import. Reach them with `client.requestJson` using the routes in the daemon README.
</Aside>

## Example: structured error handling

```typescript
import { DaemonHttpError, DaemonConnectionError } from '@animaos/sdk';

try {
  await client.agents.run(agentId, { text: 'Hello' });
} catch (error) {
  if (error instanceof DaemonHttpError) {
    console.error(`Daemon error ${error.status}:`, error.body);
  } else if (error instanceof DaemonConnectionError) {
    console.error('Cannot reach daemon:', error.cause);
  } else {
    throw error;
  }
}
```
