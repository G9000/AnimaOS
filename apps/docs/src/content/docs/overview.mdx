**animaOS** is an agentic operating system: persistent AI agents, memory, tools and automations in one personal workspace. It runs on your computer or your own server, on top of your existing operating system. You choose the models, connect the tools, and decide how independently your agents work.

You talk to your agent (anima) in the web console or through a connected chat app. You give it work, let it bring in helpers, and follow its plans, actions and results in one place. Its context carries across conversations through saved memory and reusable skills.

This site documents the developer surfaces: the **TypeScript SDK**, the **`animaos` CLI** and the **terminal UI**. All three are thin clients of one process, the **Rust daemon**, which owns agents, memory, schedules, connectors and execution.

## Architecture

```text
 web console   SDK (TypeScript)   CLI (animaos)   TUI (animaos launch)   Telegram / Discord
      \              |                 |                  |                    /
       \_____________|_________________|__________________|___________________/
                                       |  HTTP + SSE
                         +-------------v--------------+
                         |   Rust daemon (anima-daemon)|   :8080 in development
                         |   Axum host, owner auth,    |   :8787 when installed
                         |   connectors, persistence   |
                         +-------------+--------------+
                                       |
        anima-core | anima-memory | anima-swarm | anima-schedule | anima-harness
                                       |
                              model providers (OpenAI, Anthropic,
                              Google, Ollama, OpenRouter, and more)
```

The reusable runtime lives in the Rust workspace under `packages/core-rust` and stays independent of any host. The daemon (`hosts/rust-daemon`) wraps it and exposes HTTP and server-sent events. The SDK, CLI and TUI never run agent code themselves; they call the daemon.

<Aside type="note">
  The Rust daemon is the only supported host today. Earlier TypeScript runtime packages, the mod system and the agency generator have been removed. `animaos create` scaffolds a single agent workspace, and `bun dev --host` accepts only `rust`.
</Aside>

## Ways to run it

| | Packaged `anima` | From the repository |
|---|------------------|---------------------|
| What it is | An installable program that wraps the daemon, embeds the web console, and adds a tray icon, supervisor and self-updater | The development workflow |
| Start | `anima setup`, then `anima` | `bun dev --host rust` |
| API and console | Port `8787` (control port `8788`) | Daemon on `8080`, web console on `4200` |
| Data | `~/.animaos-swarm/` | Its own development data |

The packaged program's commands include `anima`, `anima setup`, `anima status`, `anima start`, `anima stop`, `anima restart`, `anima quit`, `anima logs`, `anima update` and `anima config`. It is a separate copy from a development daemon; the two never share data or credentials. See the [packaged Anima guide](https://github.com/G9000/animaOS-SWARM/blob/main/apps/contributor-docs/src/content/docs/packaged-anima.md) for install, updates and limits.

For development, run from the repository root:

```bash
bun install --frozen-lockfile
bun x nx run @animaOS-SWARM/sdk:build
bun dev --host rust
```

Then open `http://localhost:4200`, create your companion, select its workspace and connect a model provider. `bun run daemon` starts the daemon alone.

## Key concepts

### Agents

An agent is a persistent runtime registered with the daemon: a model and provider, a system prompt and character fields, tools, settings, memory, and a main conversation. You grant tools per agent, and an approval policy gates what they can do.

[Learn more about Agents](/sdk/agents/)

### Sessions and runs

Conversations are **sessions**. Sending a message creates a **run** that executes in the background; you follow it on a live event stream, and can steer or stop it. This is the model the web console uses.

[Learn more about Sessions & Runs](/sdk/sessions/)

### Swarms

A swarm is a manager and workers coordinated by a strategy: `supervisor`, `round-robin` or `dynamic`. The daemon streams their messages, tool calls and token usage.

[Learn more about Swarms](/sdk/swarms/)

### Memory

Agents keep facts, observations, task results and reflections, plus two always-on core blocks (About you and Agent notes). Retrieval fuses keyword matching, embeddings, relationships, temporal facts, recency and importance. Memory can be exported as JSON or Markdown.

[Learn more about Memories](/sdk/memories/)

### Approvals, jobs and automations

Tool calls are classed as read, write, exec, network or delegate; by default only exec asks. Jobs and automations let agents work without a chat message, and an unattended run that needs a decision waits for the owner.

[Learn more about Approvals](/sdk/approvals/) and [Jobs & Automations](/sdk/automations/)

### Persistence and durability

By default the daemon runs ephemeral. Configure a control-plane file (or Postgres), history and a memory store to keep agents, conversations and memories across restarts; the packaged program does this for you. A restart marks interrupted runs for review instead of replaying them.

## Getting started in 60 seconds

```bash
# 1. Start the daemon (from the repository root)
bun run daemon

# 2. Give it a model (or connect one in the web console)
export OPENAI_API_KEY="sk-..."

# 3. Build the CLI and run one task
bun run build:cli-sdk
bun run animaos run "Say hello" -m gpt-4o-mini
```

Or use the TypeScript SDK for full control:

```typescript
import { agent, createDaemonClient } from '@animaOS-SWARM/sdk';

const client = createDaemonClient();

const helper = await client.agents.create(
  agent({
    name: 'helper',
    provider: 'openai',
    model: 'gpt-4o-mini',
    system: 'You are a helpful assistant.',
  })
);

const result = await client.agents.run(helper.state.id, {
  text: 'What is the capital of France?',
});

console.log(result.result.data?.text);
```

<Aside type="caution">
  AnimaOS is under active development. Connector and tool capabilities have setup and scope limits, browser work is scoped, and interrupted work may need review after a restart. The daemon README and the capabilities endpoint describe current limits.
</Aside>
