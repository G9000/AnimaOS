In an interactive `animaos launch` session you type tasks and slash commands in the input bar. Anything that does not start with `/` is sent as a task. The commands available change with the view and with daemon state.

<CardGrid>
  <Card title="Healthy">
    Tasks are accepted, and the TUI streams swarm events, tools and results live.
  </Card>
  <Card title="Daemon down">
    Tasks are paused, and commands such as `/health` and `/help` keep working.
  </Card>
  <Card title="Recovered">
    The TUI says so explicitly, and tasks work again.
  </Card>
</CardGrid>

## Slash Commands

In the swarm view:

| Command | Description |
|---------|-------------|
| `/agents` | Browse and edit the agent profiles from `anima.yaml` |
| `/history` | Browse past runs |
| `/resume [label]` | Browse saved runs, or open one by label (prefix and partial matches work; it suggests close ones) |
| `/rename <label>` | Name the current (or most recent) saved run |
| `/delete <label>` | Delete a saved run by exact label; repeat the command to confirm |
| `/undo` | Restore the last deleted saved run |
| `/undo-drop` | Discard the oldest queued undo; repeat to confirm |
| `/undo-status` | Show the deleted-run undo queue |
| `/trace` | Inspect the messages and tool activity of the last run |
| `/result` | Open the full last result |
| `/status` | Show session state: phase, task, agents, daemon, message and tool counts, history size |
| `/health` | Recheck daemon connectivity and report healthy, recovered or unavailable |
| `/retry` | Rerun the last task (hidden while the daemon is down) |
| `/help` | List the commands available right now |
| `/clear` | Clear the session and delete the saved history file |
| `/exit` (or `/quit`) | Leave the TUI |

In a result view, `/back` returns to the swarm view, and `/delete` and `/rename` act on the open run. While the daemon is down, a result view offers `/health` and `/help` instead of `/retry`. An unknown command shows `Unknown command: /name. Type /help for commands.`

Saved-run labels are a name you give with `/rename`. `/resume`, `/rename` and `/delete` complete labels with Tab.

## Keys

| Key | Where | Action |
|-----|-------|--------|
| `Enter` | Input bar | Submit the task or command (or pick the highlighted command) |
| `Tab` | Input bar | Complete the highlighted slash command or saved-run label |
| `↑` / `↓` | Input bar | Move through command suggestions; otherwise recall earlier inputs (up to 100) |
| `Ctrl+R` | Input bar | Search earlier inputs; press again for the next match, Esc to restore your draft |
| `Ctrl+O` | Swarm view, between tasks | Open saved runs to resume |
| `Ctrl+N`, `Ctrl+P`, `Ctrl+Y` | After a `/resume` with several matches | Move through the matches and open the selected one |
| `s` | While a task is running | Show status |
| `Ctrl+C` | Anywhere | Quit |

Browsers inside the TUI (History, Trace, Agents) share a few keys: `↑` and `↓` to move, `/` to search, `n` and `N` for the next and previous match, `Esc` to clear a search, and `q` (or `Esc`) to go back.

## Operator States

### Healthy daemon

Task submission is enabled. The TUI streams events, tool traces, token updates and final results as they arrive.

### Daemon unavailable

When a health check fails (at launch, or about every 5 seconds while the TUI is open):

- a warning appears above the panels, and the status bar shows `daemon: down`
- the input bar reads `daemon down - tasks paused; use /health or /help`, and plain tasks are refused
- `/health` and `/help` still work, as do the browsing commands (`/history`, `/trace`, `/result`, `/agents`)

### Recovery

When the daemon answers again, the TUI shows a recovery message and re-enables tasks. `/health` forces a recheck at any time.

### Missed events

If the daemon reports that the TUI's stream fell behind, the status bar shows a `gaps` count. Rerun the task if you need a complete trace.

<Aside type="tip">
  For one plain-text answer, use `animaos run`. Use `animaos launch` for a session with history, retry, live telemetry and recovery.
</Aside>
