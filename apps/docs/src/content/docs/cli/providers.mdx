The CLI accepts the same provider names across `create`, `launch`, `run` and `chat`. `deterministic` is also accepted: it is a scripted, non-LLM provider built into the daemon for offline testing, and `create` falls back to it when no remote provider has credentials.

The CLI only detects and forwards credentials. The daemon makes the model calls, and it has its own sources of keys (its environment, keys saved in the web console, a ChatGPT subscription), so a key does not have to come from the CLI at all.

When several variables are listed, the CLI uses the first one that is set and non-empty. Default endpoints are each provider's public API (for example `https://api.openai.com/v1`, and `http://127.0.0.1:11434/v1` for Ollama).

## Runtime Environment

| Variable | Read by | Description |
|----------|---------|-------------|
| `ANIMA_DAEMON_URL` | CLI | Daemon base URL for daemon-backed commands (default `http://127.0.0.1:8080`) |
| Provider key variables | CLI and daemon | Forwarded by the CLI on each request; also read by the daemon itself |
| Provider base-URL variables | CLI and daemon | Override provider endpoints such as `OPENAI_BASE_URL` or `OLLAMA_BASE_URL` |
| `ANIMAOS_WORKSPACE_ROOT` | Daemon | Initial workspace root for the daemon's file tools (a configured workspace replaces it) |
| `ANIMAOS_USER_ID`, `ANIMAOS_USER_NAME` | CLI | Defaults for `animaos assistant chat` |

## Override Rules

- `--api-key` overrides the environment for one CLI invocation.
- For `launch`, `--api-key` applies to the agency's provider only; an agent that sets a different `provider` in `anima.yaml` uses that provider's own environment variables or credentials stored by the daemon.
- `create` falls back to `deterministic` when no remote provider is configured, and uses `--api-key` only to detect which provider is set up.
- Daemon-backed commands forward the resolved key and base URL as the agent's `settings.apiKey` and `settings.baseUrl`, so changing keys does not need a daemon restart.

## Common Examples

```bash
# Local Ollama
OLLAMA_BASE_URL=http://127.0.0.1:11434/v1 \
animaos run "Summarize the plan" -p ollama -m qwen2.5:7b

# A daemon on another port
ANIMA_DAEMON_URL=http://127.0.0.1:8787 \
OPENAI_API_KEY=sk-... \
animaos agents list

# Offline scaffolding with the deterministic provider
animaos create agent local-helper -d "Summarize notes" -p deterministic
```

<Aside type="tip">
  Keep provider credentials in the environment, use `--api-key` only for a temporary override, and use `ANIMA_DAEMON_URL` only when you intentionally target a different daemon. Credentials you connect in the web console (Settings, Model) are stored by the daemon and need no CLI flag at all.
</Aside>
